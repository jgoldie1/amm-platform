# TRYAMM My World + We Are the World

## My World
My World is the user-owned personal universe inside TRYAMM. It is the private/personal layer where a person can organize identity, creator profile, media, HoloForge assets, games/worlds, music, purchases, services, events, friends/followers, accessibility/language preferences, wallet/history and private memory.

Privacy rule: My World is owner-controlled. Private data is never made public simply because the user enters We Are the World. Sharing is explicit and scoped by object, audience and duration.

My World connections:
- Stubbs AI / HoloGPT personal context
- My Vault
- HoloForge assets
- HoloMusic catalog and playlists
- Omni Box media projects
- StarVerse auditions and creator identity
- Games/Living Worlds avatars, inventories and saved state
- Marketplace store/purchases
- Wallet/Money Engine history
- PropertyVerse saved properties/projects
- Accessibility and language settings
- LIVE schedule, replays and clips

## We Are the World
We Are the World is the shared global social/world layer. It connects public and permissioned creator worlds, LIVE rooms, events, communities, games, music, Free TV, news, debate, faith channels, shopping, education, services and cultural discovery across countries and languages.

Global discovery dimensions:
- country/region
- language
- interest/topic
- LIVE / PK / shopping / music / news / debate / faith / games / movies / TV
- accessibility availability
- age/safety lane
- public, followers, invite-only or private community visibility

## Shared operating backbone
Both layers use the same common operating system:
Holo Identity → Quantum Security → HoloNet → Quantum Lag Buster → Supabase state/memory → LiveKit/realtime → HoloForge/media processing → rights/moderation/compliance → HoloMusic/Omni Box/Isaiah AI TV/Free TV/Games/Marketplace → Money Engine → Aniyah Cross-Border Payments where supported.

## World transition
My World → choose what to share → policy/rights/moderation check → publish to We Are the World → audience interaction → follows/chat/gifts/PK/commerce → earnings/history → results return to My World.

## Creator path
Create in My World → rehearse privately → publish to We Are the World → go LIVE → perform/debate/teach/play/sell → record → create reels/clips → distribute → monetize → save audience/earnings/media back into My World.

## Safety and privacy
- Private memory and Vault content never become globally searchable by default.
- Location sharing must be coarse or explicit; exact private addresses are not part of public presence.
- Religious, health, financial and other sensitive data remain private unless the user knowingly chooses a specific public disclosure.
- Money, identity, rights and moderation gates fail closed.
- Youth/minor lanes require stronger privacy/safety defaults.

## What this enables
TRYAMM stops behaving like a collection of disconnected pages and becomes a persistent personal-to-global world system: each user has a private home universe and can selectively step into a shared global universe without losing identity, state, media, accessibility settings, earnings or history.
