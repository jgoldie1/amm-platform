## Recovery rules going forward

1. Every newly rediscovered product gets a permanent Product ID and archive citation/source pointer.
2. Never delete aliases; map old names to the current canonical product name.
3. Separate exact recovered product from product-family recollection.
4. For cosmetics/hair/food/battery/medical/vehicle/aerospace products, do not claim safety/performance without verified specifications and testing.
5. Every product receives status, source path, owner/legacy designation, customer, monetization model, dependencies, fulfillment path and launch priority.
6. Conversation memory is supporting evidence; GitHub + Supabase + Library recovery docs are the durable source of truth.
